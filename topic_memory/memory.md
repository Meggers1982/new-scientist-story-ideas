# Topic Memory: memory
_Last updated: 2026-08-22_

## Established findings
- Enactment/physical rehearsal reliably outperforms mental simulation and passive encoding for both intentions and instructions, across ages 8–60 and independent of vision (PMIDs 42627881, 42622513; Aug 2026).
- Cognitive offloading raises performance under high load but carries its own error mode and suppresses encoding when access is expected (PMIDs 42607389, 42622798; Aug 2026).
- Sleep supports not just item memory but source memory and downstream behaviour (who said what, conversational efficiency) (PMID 42492165; Jul 2026).
- Eye-movement/dual-task recall reduces vividness and unpleasantness of aversive memories; effect appears emotion-general, not fear-specific (PMIDs 42622123, 42531952; Aug 2026).

## Emerging threads
- EMDR mechanism being dismantled: works without conscious reactivation (subliminal cues) and without fear dominance — pushes toward a working-memory-taxation account, still lab-analogue only (42531952, 42622123).
- Trauma/PTSD reconceived through memory mechanics rather than fear: positive-memory therapy, within-day-only symptom coupling, and four person-specific network "shapes" (42623486, 42607016).
- GLP-1 drugs accruing observational cognitive signals via EHR mining, with commercial data-company authorship (42624612) — watch for RCT follow-up and conflict-of-interest scrutiny.
- Data-quality/meta-science concern: ~a third of online participants go off task during encoding; warnings don't fix it (42608507).
- Neuromodulation gap: tDCS improves sleep plus offline consolidation in insomnia (n=42, 42537590), while connectivity-guided iTBS moved the network but not the targeted memory (n=1, 42610835).
- Neural architecture: repeating paired perception/memory regions across cortex, now a fourth pair in parietal lobe (42624782).
- Under-covered ageing target: trainable pragmatic/social comprehension in older adults, gains specific and not memory-mediated (42629485, uncontrolled n=24).

## Feature ideas already pitched
- Aug 2026: "Memory is enacted, not stored" — embodied encoding (enactment, handwriting) versus the cost of offloading to notes, AI summaries and voice interfaces (42627881, 42622513, 42607453, 42622798, 42607389). Pitched to New Scientist Features, BBC Future, The Atlantic, Wired.
